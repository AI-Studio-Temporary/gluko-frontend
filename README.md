# Gluko Frontend

Next.js frontend for **Gluko** — an AI-powered diabetes assistant that helps users estimate carbohydrates, calculate insulin bolus doses, log health data, and interact with an AI tutor.

## Tech Stack
- Next.js 14 (TypeScript)
- Tailwind CSS
- shadcn/ui
- Deployed on AWS EC2 / Vercel

## Setup
```bash
npm install
npm run dev
```
